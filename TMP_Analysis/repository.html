1. Repository & documents

What is in the repository and what each part is for.

Overview

The repository is a reference implementation of an IBM Z "AI Solution Template". It is a multi-container web application (React UI, FastAPI backend, MongoDB, OpenSearch) that summarizes uploaded documents and answers questions about them with retrieval-augmented generation (RAG). The LLM is not part of the repository. It is an OpenAI-compatible endpoint exposed by Red Hat AI Inference Server (RHAIIS, vLLM for Spyre). Its address is supplied through the RHAIIS_API_BASE_URL setting.

Code at a glance

PathResponsibility
backend/server.pyFastAPI app: upload with streamed summary, user check, delete, RAG chat, RHAIIS health check.
backend/rhaiis_utils.pyClient for the RHAIIS /v1/chat/completions endpoint (streaming), plus older non-streaming helpers and a simple metrics tracker.
backend/rag.pyPrompt builders for RAG, summarization and image-only questions. Multilingual (en, fr, pt, hi, de, it, el).
backend/utils.pyPDF and DOCX text extraction, line-based chunking, language detection, logging helper.
backend/mongo_utils.pyMongoDB persistence, duplicate handling, ROUGE scoring, triggers ingestion to OpenSearch, image ingestion, deletion.
backend/opensearch_utils.pyOpenSearch vector store, embeddings, retrieval with fallback, de-duplication, and the ImageRAG class (CLIP plus captioning).
backend/config.pyEnvironment-driven settings (OpenSearch host, Mongo host, embedding model, chunk size and overlap).
frontend/src/components/*Dashboard (login and tabs), HomeTab, DocumentTab, AIChatTab, SetupGuide, Header, Icons.
