2. Stated purpose

What Document_Intelligence_RHAIIS_solution_template.docx and the README say this solution is for.

Business goal

Summarize documents and provide a RAG chatbot over them, running on an IBM z17 with the IBM Spyre AI accelerator and Red Hat AI Inference Server, so the data stays on the IBM Z platform.

Pipeline as described

  1. Documents are stored in MongoDB.
  2. Information is extracted and split into chunks.
  3. Two paths run on the z17: a summarizer and a RAG pipeline that computes embeddings and stores them in an OpenSearch vector index.
  4. A Granite 3.3-8B instruct model served by RHAIIS produces summaries and chat answers.
  5. Chat answers are grounded in retrieved content and "cite or are traceable" to the sources.

Claims about Spyre

  • Spyre "accelerates the data preparation and orchestration on-platform": extraction, chunking, embedding generation and vector search.
  • Card facts quoted: 32 cores, Samsung 5 nm, up to 128 GB LPDDR5 per card, 300+ TOPS, 75 W.

Other capability claims

  • "Semantically meaningful" segments.
  • Role-aware summaries.
  • Guardrails, policy and observability.

RHAIIS setup in the template

  • Pull registry.redhat.io/rhaiis/vllm-spyre:3.2.5.
  • Run it with the /dev/vfio devices and environment variables such as FLEX_DEVICE=VF, VLLM_SPYRE_USE_CB=1, TORCH_SENDNN_CACHE_* and VLLM_SPYRE_REQUIRE_PRECOMPILED_DECODERS=1.
  • Edit the senlib config with jq.
  • Start the OpenAI-compatible vLLM server with --model ibm-ai-platform/micro-g3.3-8b-instruct-1b --max_model_len=2048 --max-num-seqs=4 --tensor-parallel-size=2.

Application deployment and use

  1. Clone the sample (spyre_enhanced_document_summarizer) and run podman-compose up --build -d.
  2. Open http://localhost:3002 and log in with a username.
  3. Upload documents. A summary is produced automatically. Use "View Details" and "Preview".
  4. Use the "AI Assistant" tab to ask questions.

The template estimates about 45 minutes for the complete setup.

The template is an operator guide plus value narrative. Its testable promises are the pipeline steps, the model, the ports and the user flow, plus the Spyre-acceleration claims. Page 5 tests each one.
