6. Issues

Defects, risks and inconsistencies found by reading the code and documents. Line numbers are approximate.

Functional bugs

#IssueLocationImpact
F1Fake RHAIIS health check with a hardcoded IPbackend/server.py ~1004-1030 (is_rhaiis_endpoint_healthy)It targets http://129.40.90.163:9000/v1/completions but sends no request. It always returns reachable: True because 200 in [200,400,422]. The exception handlers are dead code. The header indicator is always green.
F2Summary language detection is wrongbackend/rag.py ~199 and ~213-251 (build_summarize_prompt)detect_language_with_confidence returns a list of dicts, but the result is compared with strings such as "fr". Every document falls through to the English prompt, so the multilingual summaries do not work. build_rag_prompt does it correctly.
F3Same comparison flaw in the image-only promptbackend/rag.py ~279-339 (build_image_only_prompt)Not used by server.py today, so latent.
F4Python 3.12-only f-string syntaxbackend/server.py, raw_content yieldNested same-type quotes in an f-string fail to parse on Python 3.11 and earlier.
F5GET then POST fallback for /user_exists_checkfrontend/src/components/Dashboard.js vs. server.pyThe backend defines only POST. The frontend first sends a request that is bound to fail with 405.
F6Context overflow riskrhaiis_utils.py, rag.py vs. docx --max_model_len=2048Prompts of up to 10,000 characters plus up to 10,000 generated tokens exceed a 2048-token window.

Security

#IssueLocationImpact
S1No real authentication or authorizationDashboard.js, all endpoints in server.pyThe user id is a username typed in the browser and sent in requests. Any caller can read or delete another user's documents by changing user_id. The admin name is only a UI flag.
S2Permissive CORSserver.py ~151allow_origins=["*"] with allow_credentials=True.
S3TLS verification disabledrhaiis_utils.pyssl=False and verify=False expose traffic to the inference server to interception.
S4Uploads written to /tmp/<basename>server.py upload handlerConcurrent users with the same file name overwrite each other. Sensitive files stay on disk in a shared directory.
S5Chat history in localStorageAIChatTab.jsConversation content persists unencrypted in the browser and is shared by anyone using the same profile.
S6No guardrailsWhole backendNo input or output filtering, no prompt-injection handling, although the docx mentions guardrails and policy.
