4. Frontend & infrastructure

The React UI, the container image and the Compose deployment.

Frontend

A Create React App project (React 18, react-scripts 5, @carbon/react, @carbon/icons-react, Sass). App.js wraps a single Dashboard in the Carbon g100 dark theme. The API address comes from REACT_APP_API_BASE_URL.

ComponentRole
Dashboard.jsLogin screen and tab host. Username only, no password. A user named admin gets role admin; every other name gets user. After login it loads the user's stored documents from /user_exists_check.
HomeTab.jsLanding and overview content.
DocumentTab.jsUpload, streaming progress modal (parses SSE document_start, raw_content, summary_chunk events), "View Details" and "Preview", delete via DELETE /delete-file.
AIChatTab.jsChat UI. Sends query, user_id and the selected document_names to /ask-query, renders the streamed text, has a 2-minute timeout, and keeps chat history in localStorage per username.
SetupGuide.jsTwo-step onboarding checklist (upload a document, explore AI features) with links to RHAIIS documentation.
Header.jsBranding, user menu, and a service-health indicator that polls /rhaiis/health every 60 seconds.

The chat client receives and displays plain text only. It has no data structure for citations or source references.

Container image (Dockerfile)

  • Base s390x/ubuntu:noble, matching IBM Z.
  • Installs build tooling, llvm-15, Docker CE and PDF libraries, then builds Apache Arrow and PyTorch from source.
  • Installs requirements.txt and copies in backend and frontend.

Dependencies (requirements.txt)

The file mixes needed libraries (FastAPI, LangChain, OpenSearch, PyMongo, PyPDF2, python-docx, langdetect) with many that this code does not use (for example xgboost, shap, jupyterlab, ibm_db_sa, pymilvus, elasticsearch). torch and sentence-transformers are commented out because the image builds torch itself. Packages used by the code, such as aiohttp, rouge-score, colorama and Pillow, are not listed and are instead installed at container start-up by Compose.
